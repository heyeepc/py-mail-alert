# py-mail-alert- 基于文件夹监控的自动化邮件触发系统

这是一个用于练手和熟悉 Python 自动化运维、网络协议编程的轻量级项目。该系统通过监控本地特定目录，当检测到符合规范的 `.txt` 文件放入或修改时，会自动解析其内容并通过 SMTP 协议将其作为邮件（支持附件）发送出去；同时包含了一个基础的 POP3 邮件接收与解析客户端。

> ⚠️ **项目定位**：本项目主要用于技术栈练习（Watchdog 异步事件、SMTP/POP3 协议应用、文件编码处理），目前属于 **Demo/实验室阶段**，距离生产环境实战仍有一定差距（详见后文 Todo）。

---

## 🛠️ 技术栈与核心库

* **开发语言**：Python 3.x
* **文件监控**：`watchdog` (基于操作系统事件的异步文件流监控)
* **邮件协议**：`smtplib` (SMTP_SSL 465端口), `poplib` (POP3_SSL 995端口)
* **文本处理**：`chardet` (智能文本编码自动识别), `email.parser` (二进制邮件流解析)
